## cockpit 缩略图(base 驾驶舱可用性)
- **现状**:图片和视频**都没有可视缩略图**——素材表存 `链接`(百度分享链,url 字段不渲染缩略图)+ `备注`(文字描述)。选材靠点链接/读文字。
- **决策:值得做(base=驾驶舱,选材靠眼睛)**,修订 ADR-0007"不存缩略图"。**做法**:素材表加 `缩略图`(附件)字段 + `feishu_io` 加媒体上传(`/open-apis/drive/v1/medias/upload_all`,multipart→file_token)+ 打标时上传降采样预览(图片用降采样 jpg、视频用多帧拼图)。**是 schema 变更 + 新上传能力 + 回填 201 条**,作为紧接的聚焦任务做(非本轮临时塞,避免半成品)。当前过渡:`备注` 富描述 = 文字预览。
