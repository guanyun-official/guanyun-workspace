# ADR-0009 · 上量前必做的重构与合规路线图(四角度场景压测结论)

## 一句话结论
**"不做错事"这维度很强**(止于草稿、只写测试库、失败隔离降级、凭证隔离);天花板与裸奔点集中在**"该由代码守却写成社会约定/装错位置的闸"**和**"运行基座没在规模下真跑过"**。当前 4 号/数百素材/单机 = 完全够用且**正是唯一被真验证的规模**。

## 本 session 已当场修(不留)
- **合规硬伤:AI 来源就低不就高** —— 来源由**落点定不靠视觉猜**:落 `02-AI生成/` 或带生成参数 → `register` 强制 `来源=AI生成`;TAXONOMY 改"疑似 AI 就标"。(commit 当轮)防"AI 图漏判→标实拍→漏标 AI 声明→违反标识办法"。
- **ARK 降级**:重试退避 + 降采样(治 Broken pipe)+ 每图每批隔离,已验证。

## cockpit 缩略图(base 驾驶舱可用性)
- **现状**:图片和视频**都没有可视缩略图**——素材表存 `链接`(百度分享链,url 字段不渲染缩略图)+ `备注`(文字描述)。选材靠点链接/读文字。
- **决策:值得做(base=驾驶舱,选材靠眼睛)**,修订 ADR-0007"不存缩略图"。**做法**:素材表加 `缩略图`(附件)字段 + `feishu_io` 加媒体上传(`/open-apis/drive/v1/medias/upload_all`,multipart→file_token)+ 打标时上传降采样预览(图片用降采样 jpg、视频用多帧拼图)。**是 schema 变更 + 新上传能力 + 回填 201 条**,作为紧接的聚焦任务做(非本轮临时塞,避免半成品)。当前过渡:`备注` 富描述 = 文字预览。
