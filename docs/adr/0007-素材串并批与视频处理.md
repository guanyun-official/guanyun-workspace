# ADR-0007 · 素材全周期的串/并/批 + 视频处理最佳实践

- 状态:已接受(2026-07-13,真跑重标 286 张 + 视频 53GB 撞出的约束定调)
- 相关:ADR-0004(媒体唯一源)、`scripts/tag_materials.py`、`orchestrator/media.py`、`orchestrator/config.py`、[[concurrency-serial-means-protect-laptop]]

## 背景
真跑用 Doubao 重标 286 张素材时撞到两件事,逼出这份最佳实践:
1. 老串行打标又慢又脆:一张坏 heic(sips 静默失败)崩全场;整批空标签被 `zip` 静默吞→入库 0,无告警。
2. 视频:`视频底片/` 是 **53GB 佳能 raw**(median 511MB/条,最大 1.65GB)。真测发现 **baidu 直链外部访问 403、`download` 无 range**——外部工具**无法"只抽帧不下整包"**。

用户同时纠正:红线**"串行不并发" = 别把高负载压本机,不是禁并发;打标该并发**。

## 决策一:串/并/批按阶段分(护本机是那根轴)

| 阶段 | 性质 | 串/并/批 | 谁扛负载 |
|---|---|---|---|
| 拉取(netpan pull) | 网络 I/O | 有界并发 | 带宽 |
| **转码**(sips/ffmpeg) | **CPU·本地** | **本地低并发(护本机)· 服务器可高** | ★本机★ |
| **看图打标**(Doubao) | API·按图计费 | **并发 + 批**(并发=快、批=省每调用开销,成本按图不变) | 火山云 |
| 登记(feishu 写) | API 写·序号 | **串行**(gen_code 序号单调 + feishu 限流) | 飞书 |

- 旋钮:`GY_TAG_CONCURRENCY`(默认 4,护本机;服务器调高)。**打标并发+批 = 快且省;登记串行 = 序号不乱。**
- "串行不并发"红线 = **护本机负载**,不是禁 API 并发。

## 决策二:健壮性(反"一个坏点炸/吞整批")
- **每图隔离** `_prep_batch`:转码没产出/pull 失败 → 跳过记 ⚠,不炸全场。
- **每批隔离** `_tag_one_batch`:Doubao 报错 → 跳过该批记 ⚠,不炸整个文件夹。
- **不丢图** `_align`:标签少于图数 → 缺的补 `{}` 兜底(`_valid_type` 钳),**绝不静默丢**。

## 决策三:视频处理最佳实践(真测约束驱动)
1. **raw 视频底片 ≠ 素材,不入库打标。** GB 级 raw 是 `video-editing` 的**剪辑原料**;只有**剪出的成片**(短、小)才登记成 上身视频/制作过程视频 素材。这一条直接消掉 53GB 问题。
2. **真要给视频抽帧时**:下载一次 → **多帧抽帧**(`media.video_keyframe`,ffprobe 均匀取 n=3 帧首/中/尾**横向拼成一张**给 Doubao——单帧可能抽到黑帧/特写不代表整片,多帧拼一张保持"1视图1标签"批模型不破却看得到整片脉络)→ 打标 → 删视频,**永不重下**(下都下了多抽免费)。
   - **缩略图不单独存**(决策):素材表无缩略图字段,加字段=schema 变更;而**发布靠 `链接`(网盘视频分享链)、预览靠 `备注`(多帧描述已足够代表整片)**,视觉缩略图收益边际。故不存 keyframe jpg(用完即删),要视觉缩略图再议加字段。
3. **视频下载 = 重活 = 服务器干**;**本机默认关视频入库**(`GY_INGEST_VIDEO=0`)——护本机(红线本意)。tagger 默认跳视频 + 日志。
4. **视频强制视频类**:Doubao 看的是关键帧(静图),会把视频误标静图类 → `_valid_type` 按文件形态**强制落视频类**(上身视频/制作过程视频),静图误落视频类→纠回。防"视频标成上身图"。
5. **上游最优(以后)**:拍摄/上传时就生成关键帧/代理片,系统永不碰 raw。

## 后果
- 真跑验证:并发+隔离版重标静图正常;最小视频(48MB)下载一次→中点抽帧(180KB)→Doubao→强制纠正上身视频→登记→清缓存(释放 1190MB,不留本地)。
- keep 门绿(pytest / ar_check SCORE=100);`_align`/`_valid_type`/`video_keyframe` 均有单测。
- 本机不再被 53GB 视频压垮;视频入库是服务器/显式开启的事。
