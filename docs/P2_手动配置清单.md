# P2 手动配置清单（飞书 UI 一次性操作，10 分钟）

> 自动化无创建 API（实测：GET workflows 可读、无 POST 端点），以下需人在飞书 UI 配置。
> 先在**测试 Base** 配置验证：https://ccn925h7lg9d.feishu.cn/base/ZhzJbfkOsafwevsWkW8cfoILnfb

## 1. 待审推卡片（唯一必配的自动化）

路径：打开 Base → 右上「自动化」→ 新建自动化：

- **触发**：当「笔记表」的「状态」字段 → 变更为 `草稿待发`
- **动作**：发送飞书消息 → 发给：操盘手（你）
  - 卡片内容引用字段：`排期编号`、`标题`、`账号`、`文案草稿`（摘要）、记录链接
  - 若卡片编辑器支持「添加按钮→修改记录」：加两个按钮
    - 「通过」→ 将该记录 状态 改为 `已批准`
    - 「打回」→ 将该记录 状态 改为 `待出文案`
  - 不支持按钮就只留记录链接（人点进去手动翻状态）——P5 再升级。

配好后验证：把任一 `_DEMO` 记录状态翻到 `草稿待发`，手机应收到卡片；点「通过」状态应变 `已批准`。

## 2. 查看租户版本与自动化配额（只看不改）

飞书管理后台 → 工作台/套餐信息；或 Base 内「自动化」页底部用量提示。
**回填结论到 issue #3 评论**：版本 = ？，自动化次数/月 = ？
（设计上自动化只此 1 条、其余走轮询，基础版 200 次/月也够：≈6 次/天卡片推送。）

## 3. 不需要配置的（设计已排除）

- ❌「已批准 → 发送 HTTP 请求」：本地机器无公网地址收不到，事件改由推进器轮询（见 P2_设计判断.md）。
- ❌ 催拍/日报自动化：由推进器 heartbeat + hermes 出站完成，不占自动化配额。

## 4. 灵感提交表单视图（P5 补充，1 分钟）

实测表单(form)视图**无法经 API 创建**（800010505 invalid_request）——UI 操作：
灵感库 → 视图「+」→ 表单视图 → 命名「灵感提交」→ 勾选字段（灵感内容/来源链接/关联衣服）→ 复制表单分享链接发到员工群。
员工提灵感=填表单，落灵感库，推进器 daily 轮自动列入储备清单。
