# 新 session 启动句 · 大刀阔斧改体系

> 复制下面整段作为新 session 的 `/loop` 输入。先读 `docs/交接文档.md` + `AGENTS.md` + `docs/SOURCE_OWNERSHIP.md`。
> 本版把 **loop 迭代 / monitor 监控 / 里程碑轻量 verify** 三块单独拎清。

/loop 大刀阔斧改体系:把观云 workspace 从"测试绿但跑不起来的过度复杂系统",大刀阔斧砍成"能真跑起来、靠加 skill 生长的精简体系",直到第一目标 A 真跑通、体系(base/workspace/skill/agent/云盘)精简自洽、开发 issue 清零、想不出新的化简或场景缺口。

【先做】读 docs/交接文档.md(权威依据)+ AGENTS.md + docs/SOURCE_OWNERSHIP.md;独立核对基线(git log --oneline -1 / python3 -m unittest discover -s tests / python3 scripts/ar_check.py)。防虚构:任何写操作后用只读命令自证(commit 后 git log、Base 写后读回),叙述与只读命令不符以只读命令为准。

【终局 goal】能力为中心五唯一源:base(脸/账本/Note 状态机/人碰)+ workspace(薄编排器 + 账号声明·画像 + local 特化 skill)+ skill 独立仓库 qiaohe-skill(通用能力)+ agent(可换壳无状态)+ 云盘(哑存储)。一个事实一个家;人只碰 base 和素材;agent 调 skill 把每条 Note 推到下一格;新需求=加 skill 不改 schema。

【第一目标 A(跑通前不加任何精致)】挑 1 个号(ootd号 或 图文号1),有素材 → 薄执行器读声明 → 调其 gen_skill 真生成 1 条草稿 → 进飞书笔记表 → 人能看能发。

【大刀阔斧(同仓库、git 兜底、敢大删、不背沉默成本)】按交接文档 §5:砍子素材视图/usage 层、契约锁三层、playbook 校验、source-ownership 审计工具、trial 脚手架、绝大部分旧测试;移植已验证原语(feishu_io / guard 红线 / extract 采集 / accounts / llm);Base 按 SOURCE_OWNERSHIP+现实颗粒度瘦身(衣服总表去 SKU 与内容字段、删技能表、内容类型只留 tag),素材粗粒度按赛道不挂衣服。skill:每个一个目录、create-skill 建、渐进披露;通用在独立仓库、特化 local 住 workspace compose 通用、真实帖当 few-shot;skills.lock 按 remote/local 管。

【loop 迭代】每轮:从(开放 issue + 交接文档待办 + 一个真实运营场景)挑最高价值一项 → 先定验证标准/写测试再动手 → keep 门(跑通阶段以"A 能不能真跑"为准,骨架稳定后恢复 单测绿 + ar_check=100,不过就 revert)→ 一个原子 commit(git log --oneline -1 独立确认落库)。

【monitor 监控】布事件驱动 monitor 作主信号:orchestrator/lib/scripts/tests 里 .py 一变动就跑单测,红了立刻报警(silence=绿,只报红与恢复);每 ~30 分钟兜底跑 6 个 check_p*.sh + ar_check,任一不绿或 SCORE<100 报警;定期 dump 测试库 schema 与基线 diff,字段被 UI 改动即红灯。

【里程碑轻量 /verify】每落一个里程碑(一批砍除、薄执行器跑通 A、Base 瘦身一轮等)做一次轻量审:① 红线没被绕(AI 声明门/base 守卫/绝不自动发布还在)② A 仍能跑、无回归 ③ 唯一源没被破坏(无双写)④ 主动找别扭/摩擦点 → 用最佳实践分析解法 → 加到 GitHub issue(很多问题开发中才知道)。必要时派 architect/critic 子代理独立复核,不轻信叙述里的成功。

【铁律】只在测试库 ZhzJbf 操作,生产库 N9IVbi 焊死不碰;绝不自动发布,内容审+人勾 AI 声明两道人审不可自动化,防搬运出口闸;LLM/网络默认 stub 零成本,除非验证真链(extract 只读采集已验证可用);加测试库字段走 lark-cli +field-create(读回自证)→ dump_schema --base test → 登记常量 + schema_diff 白名单。

【停止条件】A 真跑通(1 号真生成 1 条能发草稿、人能发)+ 体系精简自洽(base/workspace/skill 各唯一源、无冗余无双写)+ 开发 issue 清零 + 想不出新的化简或场景缺口。
