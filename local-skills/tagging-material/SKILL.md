# tagging-material · 素材自动打标(入库归类)

**何时用**:素材从网盘投递箱增量拉下来后(`scripts/ingest_incremental.py` 已 pull+转码,给你一份『待打标清单』),你**逐个看**每份素材(图/视频封面帧),产出结构化标签,`ingest.register(...)` 落素材表。目标:**人只管拍完往投递箱一丢,归类你包**(ADR-0004、EPIC #40)。

**只打标、不出稿**。出稿是 `writing-*` 技能的事。

## 输出契约(每份素材一个 JSON)

```json
{
  "素材编号": "<清单已给的编号,原样回填>",
  "类型": "上身视频 | 上身图 | 形象图",
  "来源": "实拍 | AI生成",
  "适用账号": ["ootd号", "图文号1", "图文号2"],
  "衣服": "",
  "内容标签": ["逆光", "紫藤裙", "室内自然光"],
  "备注": "逆光上身视频·藕荷紫藤裙(GY-004)·室内自然光·唯美克制",
  "调性": "唯美克制"
}
```

字段→`register` 映射:`类型`→mtype、`来源`→source、`适用账号`→accounts(名字,登记时解析成 record_id)、`备注`→note(**衣服编号+内容标签都塞进备注**,货对板/内容寻址靠它)。

## 判据(照这几条,别拍脑袋)

### 1. `类型`(素材要能被薄执行器按类型选)
| 类型 | 是什么 |
|---|---|
| **上身视频** | 人穿着走动/展示的短视频(ootd号视频模式、官号品牌新作要) |
| **上身图** | 人穿着的静图(ootd号图文、图文号种草要) |
| **形象图** | 偏产品/形象的静图(官号品牌新作要;非上身的细节/挂拍/氛围) |

### 2. `来源`——记**像素出处**,不是"有没有被加工"(ADR-0004,最容易错的地方)
- **实拍**:像素来自真实拍摄。**哪怕经过 AI 剪辑/拼接/加字幕/调色/变速**——只要没往画面里**合成新东西**,就是实拍。→ 发布时**免勾 AI 声明**。
- **AI生成**:像素**由 AI 合成**——文生图、文生视频、AI 换脸、AI 造出画面里本不存在的人/物/背景。→ 发布时**必须勾 AI 声明**。
- 拿不准时问一句:"画面里的人和衣服,是真拍的吗?" 真拍=实拍;AI 编的=AI生成。**宁可标 AI生成**(误标实拍会漏勾声明,是红线;误标 AI生成只是多勾一下)。

### 3. `适用账号`(赛道=号×模式;素材按赛道存,不挂衣服——除官号)
- 一份实拍素材可同时适用**风格吃得下它**的多个号:唯美出片→`ootd号`;真实自然、素人感→`图文号1`/`图文号2`。别硬塞不搭调的号。
- 号与模式:`ootd号`(视频唯美OOTD/图文唯美OOTD)、`图文号1`/`图文号2`(素人图文种草)、`官号@巧荷·东方美学`(品牌新作展示)。
- 拿不准适配哪个号 → `适用账号` 留空,登记成"未归赛道",事后 `ingest.orphans()` 会捞出来补挂(容错,不硬猜)。

### 4. `衣服`——**只有官号品牌新作绑衣服**(货对板红线 #36)
- 官号品牌新作展示=唯一"衣服特定"模式:必须认出是哪件(对 `brands/巧荷/knowledge_base/` 里的衣服 KB,如 `GY-004 藕荷紫藤裙`),填衣服编号(也写进备注)。认不出的衣服**别编**——留空,标注"待确认衣服"([[anti-hallucination-discipline]]:照片看不出的产品知识不能造)。
- 其它号(ootd/图文种草)**不绑衣服**,`衣服` 留空。

### 5. `内容标签` / `备注`(内容寻址 #38 靠它)
- `内容标签`:画面客观特征——光线(逆光/柔光/夜景)、场景(室内/户外/园林)、衣服颜色/纹样、动作。出稿时"要一条逆光的"就靠这个精准选。
- `备注`:把 类型+衣服编号+内容标签+调性 串成一句人读得懂的话(货对板查 `编号|备注`、内容寻址查备注,都读它)。

## 段指针(ADR-0004 §4:用某段不物化新文件)
一条长视频里只想用某几段 → **别切成新文件**。给这条视频登记时,或事后新登记一条"段素材":`链接`=原视频网盘指针、`备注` 用 `ingest.segment_note(原编号, "00:12", "00:27")` 生成、`来源`**继承原视频**、`类型`随原视频。人/薄执行器一看备注就知用哪段。只有真要拼接/合成成片才走剪辑技能→回传 `03-成片/`→新登记。
