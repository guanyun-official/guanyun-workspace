# writing-ootd-caption · ootd号 出稿(视频/图文两模式)

给 ootd号(巧荷｜OOTD,服装设计师人设)出稿。总调性:**唯美、克制、意境;不考据**。
**按内容类型选一套 SOP,别混**:
- **视频唯美OOTD** → A 标题 + **B 25-30s 逐字稿**
- **图文唯美OOTD** → A 标题 + **C 几句配图短文**

## A. 标题(两模式共用:短意境句)
- 格式 `OOTD｜<意象短句>`,对仗/通感/留白;短,宁留白不凑字。
- 视频帖真实标题(few-shot):`OOTD｜宋代风雅，粉蝶入绢` / `蓝罗裁夏，风入大明` / `寒玉疏枝` / `孔府遗风，月影入罗` / `冰纹凝素，雪花含晖`;偶尔古今钩子 `原来500年前我们就有polo衫了！`
- 图文帖标题可略暖、带一点小情绪(承本号真实图文帖):`紫藤花汉服穿上身也太温柔了吧💜`(赞60·本号最高) / `把初夏穿成一身云粉浅白` / `正绢宋制也是终于穿上啦！` / `明代也有自己的夏日Polo衫`。

## B.【视频模式】25-30s 逐字稿(时从今式四层·压缩)
> 只学结构、绝不抄原句。25-30s ≈ 100-140 字,每层约 1 句:
1. **诗意开篇** · 2. **纹样/意象**(只取寓意,不展开朝代/形制/工序) · 3. **面料质感**(面料名+通感,解"显胖/厚重"顾虑) · 4. **场景+气质收尾**。
- 尾部 3-5 个我方标签;压缩纪律:砍铺陈、口播顺口、别凑字。

## C.【图文模式】几句配图短文
> 图文帖 = 一套上身图 + 几句短文。**比视频逐字稿更短更暖**:承标题的意境,写光/色/身姿 + 一点小情绪。**仍是克制设计师腔,不是素人安利**(种草是图文号的活),不口语化、不上价值、不硬广。3-4 句足矣,配图说话。
- 尾部 3-5 个我方标签(汉服/新中式/穿搭)。

## 何时用 / 边界
- 账号=ootd号。视频剪辑走 `video-editing`(需分镜时 `qiaohe-video-script`)。
- **不是**素人种草(图文号 `writing-amateur-ootd`)、**不是**官号品牌硬广(`writing-brand-newpiece`)。
- **不考据**:不写形制/朝代/几经绞/非遗工序;看不出的面料/工艺留白,严禁编造。

## 交出什么
一条待人审草稿:**标题** + (视频→**25-30s 逐字稿** / 图文→**几句短文**,标注约字数)+ 建议素材(视频取视频段;图文取上身图)+ 剪辑要点(视频)。
**发布人手、AI 声明人勾;出口过防搬运闸(不含时从今/对标原句)。**
