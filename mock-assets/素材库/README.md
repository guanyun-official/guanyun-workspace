# 模拟素材库（mock，开发 #32 素材选择用）

> 非真实媒体，占位文件。给薄执行器接「选素材」能力(issue #32)当开发夹具。真实素材走 `GY_ASSET_ROOT`(默认 `~/素材库`)。

## 素材管理模型（大刀阔斧后定案，SOURCE_OWNERSHIP §4）

**存按批次,选/挂按赛道(账号×模式)——不按衣服、不按 SKU、不一号一 folder。**

- **磁盘按「拍摄批次」存**:一次穿搭拍摄 = 一个文件夹 `素材库/{拍摄批次}/{文件}`。一批产出混合媒体(上身视频/上身图/形象图/空镜…),不同号取不同面(ootd号取视频、图文号取图、官号取视频+形象图)。按批次存避免"一号一 folder"跨号重复。
- **「按赛道」是投影靠 tag,不靠目录**:每条素材在 base「素材表」打 `类型`(上身视频/上身图/形象图… base registry vocab)+ `适用账号`(link,可多号)。
- **薄执行器选素材**(#32):对某号,按 `playbook.material_needs`(值 ⊆ base 类型 vocab)筛 `素材表` 中 `类型` 命中 + `拍摄状态=已拍`(+ 可选 `适用账号` 含该号)的候选,挂进笔记表「关联素材」。
- 大文件不进 Bitable;`素材表.相对路径/链接` 存相对路径,表不当媒体库。
